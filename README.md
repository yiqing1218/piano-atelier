# Piano Atelier

一个面向 Windows 的离线钢琴与乐谱自动演奏桌面应用原型。

支持两种模式：全曲统一为选定乐器，或按 MIDI 原始乐器及鼓轨多轨演奏。现有 133 个可选项：128 个 GM 预置、4 个独立实录选项及标准鼓组；支持每轨自行改配器。直接导入 MIDI、MusicXML、MXL。PDF/图片识谱保留为可选旧接口，不是本版使用前提。没有混响或合唱效果。

2026-10-18：已内置 Salamander Yamaha C5 实录钢琴，87 项自动化测试与浏览器冒烟检查通过。**尚未生成 Windows 安装包**：当前环境缺 Rust/Cargo、MSVC/Windows SDK。完整检查记录见 [docs/VERIFICATION.md](docs/VERIFICATION.md)，验收清单见 [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md)。

## 当前原型已经包含

- 完整 88 键屏幕钢琴（A0–C8）。
- 鼠标/触控按下发声，释放、取消、捕获丢失或窗口失焦时释放对应音符；支持多音演奏。
- 电脑键盘多行键位映射；通过八度按钮移动映射范围。
- MIDI (`.mid/.midi`) 导入与自动播放。
- MusicXML (`.xml/.musicxml`) 与压缩 MusicXML (`.mxl`) 解析，包括和弦、休止、多声部、弱起、速度变化及匹配的延音线。
- 播放/暂停、停止、进度拖动、速度调整、播放头与音符时间轴。
- 本地 SoundFont (`.sf2/.sf3/.dls`) 导入；音源会保存在浏览器 IndexedDB 中。
- 默认自动加载内置 Yamaha C5 立体声实录采样，覆盖 A0–C8、四档真实力度。只有采样加载失败时才使用明确标注的合成备用音色。
- Windows 桌面端保留 Audiveris 本地 OMR 调用接口；只有实际输出存在且解析通过才显示完成。本次未运行真实 Audiveris 识谱。
- 浏览器开发模式可导入 MIDI/MusicXML；图片/PDF 只显示本地预览和识谱提示。完整 OMR 调用需要桌面版。

## 开发环境

建议使用 Windows 10/11、Node.js 20 LTS 或更新的 LTS、Rust stable，以及 Microsoft C++ Build Tools。Tauri Windows 构建通常还需要 WebView2 Runtime。

### 1. 安装前端依赖

在项目根目录执行：

```powershell
npm install
```

启动开发服务或构建时，会将锁定版本 npm 包内的钢琴采样、署名和 SoundFont AudioWorklet 处理器复制到 `public/`，再随应用本地打包。采样来自安装阶段下载的包，运行期间不会访问 CDN。后续可用 `npm ci` 安装相同依赖。

### 2. 先运行浏览器开发模式

```powershell
npm run dev
```

打开终端显示的本地地址。开发模式不需要联网访问外部 CDN，但首次 `npm install` 需要从 npm 下载依赖。

### 3. 运行 Windows 桌面版

```powershell
npm run tauri dev
```

### 4. 构建前端

```powershell
npm run build
npm test
```

### 5. 构建 Windows 安装包

```powershell
npm run tauri build
```

安装包目标为 NSIS。第一次打包需要完成 Rust 与 Tauri 构建工具的配置。

配置使用离线 WebView2 安装器：打包阶段可能下载该安装器并增大包体积，最终用户安装时不需要在线下载 WebView2。当前尚未完成真实安装验证。

## 选择乐器与多轨模式

在时间轴上方选择“统一乐器”或“多轨演奏”。多轨列表中每条音轨都有独立的乐器下拉框和音量滑块；“自动”恢复源配器。统一乐器会将全部音轨（含原鼓轨）改用所选乐器；多轨模式按 MIDI 的 GM Program 和鼓轨演奏，钢琴继续走 Yamaha C5 或用户自选钢琴音源。多轨时乐器下拉框只影响键盘试听。切换模式/乐器会暂停并保留进度，点击播放继续。

“多轨演示”按钮可直接试听六条音轨；也可导入 `tests/fixtures/band-demo.mid`。MuseScore General 0.2 约 39.9 MB（MIT）；补充实录库约 83.7 MB（CC0），新增二胡、小号、大号和尤克里里。源文件随仓库提供，构建时校验 SHA-256 并离线打包：[多乐器音源许可](docs/INSTRUMENT_SAMPLES_LICENSE.md)。没有混响。

鼓组使用 GM 鼓键位，C2 为底鼓、D2 为军鼓、F♯2 为闭镲；统一鼓组不自动编配节奏。MusicXML 暂不读取配器，默认钢琴，可使用统一乐器切换音色。当前不还原 MIDI 控制器、弯音及 GS/XG 扩展音色库；多轨匹配仅指 GM 乐器与音符。

## 导入高品质钢琴音源

启动后默认即可使用 Yamaha C5 实录钢琴。若之前导入了测试音源或不满意的 SoundFont，点击“使用内置实录钢琴”即可切换，并清除旧的默认音源设置。

点击左侧“加载 SoundFont”，选择自己有权使用的 `.sf2`、`.sf3` 或 `.dls` 文件。应用将音源保存在本地 IndexedDB，后续启动时会尝试重新加载。高质量多层采样钢琴音源可能占用几十到数百 MB 内存。

## 配置图片/PDF 识谱

1. 安装 Audiveris，并确认其可在本机独立运行。
2. 在左侧“本地识谱引擎”中填入 Audiveris 启动器路径，例如 `C:\...\Audiveris.bat` 或可执行文件路径。
3. 在 Windows 桌面版中导入 PDF 或清晰的乐谱图片。
4. 识别结果将导出为 MusicXML，再进入本应用的解析与播放流程。

Audiveris 命令行调用采用 `-batch -export -output ... -- input` 形式。不同版本安装方式可能不同；若启动器路径或 Java 环境不正确，应用会显示错误信息。

## 离线原则

- 正式运行时不调用云端识谱 API。
- 不使用远程 CDN 加载 JS、字体、音源或模型。
- 第三方依赖和 SoundFont 资源必须在构建/配置阶段放入本地。
- 若要发布给他人，必须逐项检查依赖、音源和识别引擎的许可证。


## 本地曲库、循环与音量

成功解析的 MIDI / MusicXML / MXL 自动写入本地 IndexedDB 曲库。内容 SHA-256 相同的文件只保留一份，改名也不重复；不同格式/不同字节的版本视为不同文件。左侧列表可加载、删除，删除只移除数据库记录，不删除原磁盘文件。每首的播放模式、乐器及逐轨音量一起保存，重开后从曲库选择即可恢复。

曲库支持播放一次、列表循环、随机播放、单曲循环。随机在多首时避开刚播放的一首；只有一首时可重复。列表按导入时间排序。总音量和每轨音量均可调到 0 实现静音；音量可在播放时调整，改乐器会暂停并保留进度。

数据库属于当前应用/浏览器的本地用户数据；换端口/域名/浏览器不是同一个曲库，清除站点数据或卸载时可能丢失，请保留原始乐谱文件。尚无曲库备份/迁移功能。

## 导出音乐

- “导出 WAV 音频”：按当前配器、逐轨/总音量及速度从本机音源离线渲染，44.1 kHz 双声道 PCM16，包含 Yamaha C5/自选钢琴和真实补充录音；保留额外 5 秒尾音。超过满幅时整体衰减避免削波。最长播放时长 10 分钟，以控制内存。支持进度和取消。
- “导出 MIDI”：保留当前绝对时间（含速度变化后的时长）、音符、逐轨乐器及音量 CC。多于 15 个旋律声部使用 MIDI Port 元事件。它不是音频，不携带任何采样，专属录音采用 Bank MSB 1 的 Program 24/56/58/110；外部播放器需加载对应音源。自选钢琴本体同样不嵌入 MIDI。
- 导出包含整首曲目，不包含键盘临时弹奏；WAV 导出会先暂停当前播放。运行无需互联网，浏览器预览仍须保持本地静态服务可达。桌面版使用原生“另存为”对话框和二进制 IPC 写入，取消保存不会显示成功；该原生路径仅有桥接单元测试，尚未通过实际 Windows 构建。
- 这些导出基于当前已解析的音符；未解析的反复、踏板、弯音等不会凭空补入。原 MIDI 的音量/表达控制器仍未完整导入，重新导入导出 MIDI 时需按界面提示重新设置音量。
